
# Diamond Price Prediction App 💎

Интерактивное веб-приложение для прогнозирования стоимости бриллиантов на основе их физических и качественных характеристик. Проект разработан в рамках расчетно-графической работы по курсу "Машинное обучение и большие данные".

Ссылка: https://diamonds-ml-app.streamlit.app/prediction

## 📖 О проекте

Приложение использует ансамбль из 5 моделей машинного обучения для оценки цены бриллианта. Пользователь может ввести параметры (вес, огранку, цвет, чистоту и т.д.) и сравнить предсказания нескольких моделей одновременно.

Модели были обучены на датасете `diamonds.csv`, включающем предобработку данных (обработка выбросов, кодирование категориальных признаков, генерация новых признаков).

## 🛠️ Технологии

- **Язык:** Python 3.12
- **Фреймворк:** Streamlit (для веб-интерфейса)
- **Библиотеки ML:** Scikit-learn, CatBoost
- **Визуализация:** Matplotlib, Plotly
- **Управление зависимостями:** Poetry


## 🚀 Запуск приложения

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   # или, если используете Poetry:
   poetry install
   ```

2. **Запустите приложение Streamlit:**
   ```bash
   streamlit run home.py
   ```

## 🧠 Модели

В приложении доступны для сравнения следующие модели (все они сохранены в папке `models`):
1.  **Boosting** (Градиентный бустинг)
2.  **CatBoost** (Специализированный бустинг для категориальных данных)
3.  **Bagging** (Бэггинг)
4.  **Stacking K-Best** (Стекинг с отбором признаков)
5.  **MLP K-Best** (Нейросеть с отбором признаков)
